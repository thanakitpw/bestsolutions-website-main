## P0 — ต้องแก้ก่อน

### P0-1 · ทุกหน้าไม่ถูก cache เลย (ISR ตายทั้งเว็บ)

```
GET /th            → cache-control: private, no-cache, no-store, must-revalidate
                     x-vercel-cache: MISS   ttfb 1.12s
GET /th/about      → เหมือนกัน            ttfb 0.67s
GET /th/services   → เหมือนกัน            ttfb 0.70s   (ทดสอบ 9 หน้า MISS ทั้งหมด)
```

ทุก page มี `export const revalidate = …` (60–3600) แต่ **ไม่มีผลเลย** เพราะ:

1. `utils/supabase/queries.ts` — `db()` เรียก `await cookies()` ทุก query → Next บังคับ dynamic rendering ทั้ง route
2. `proxy.ts` — เรียก `supabaseUpdateSession(request)` กับ **ทุก** public request → `auth.getUser()` ยิงไป Supabase เพิ่มอีก 1 round-trip ต่อ pageview

ผลกระทบ: TTFB 0.6–1.1s ทุกหน้า · ยิง Supabase ทุก pageview (cost + rate limit) · crawl budget เสีย · เป็นต้นตอ LCP ใน P0-2

แก้: public read ทั้งหมดไม่ต้องใช้ cookie (RLS anon อยู่แล้ว) → ใช้ anon client แบบไม่มี cookie, และ `proxy.ts` ข้าม `updateSession` สำหรับ path ที่ไม่ใช่ `/admin`
