## FAQ

| ส่วน | ข้อความเดิม | ข้อความใหม่ |
|---|---|---|
| Eyebrow chip | ● FAQ | |
| H2 | คำถามที่พบบ่อย | |
| FAQ 1 — Q | ควรเริ่มด้วยงบโฆษณาเท่าไหร่? | |
| FAQ 1 — A | ขึ้นกับเป้าหมายและตลาดของธุรกิจ เราจะช่วยประเมินงบเริ่มต้นที่พอให้เก็บข้อมูลและปรับแคมเปญได้อย่างมีเหตุผล | |
| FAQ 2 — Q | ค่าบริการคิดอย่างไร? | |
| FAQ 2 — A | คิดตามขอบเขตการดูแล จำนวนช่องทาง และความซับซ้อนของแคมเปญ โดยแยกค่าบริการออกจากงบโฆษณาให้ชัดเจน | |
| FAQ 3 — Q | ROAS เท่าไหร่ถึงเรียกว่าดี? | |
| FAQ 3 — A | ขึ้นกับ margin, ราคาสินค้า และเป้าหมายของแคมเปญ เราจะตั้งตัวชี้วัดร่วมกันก่อนเริ่ม เพื่อให้รู้ว่าควรดูตัวเลขไหนเป็นหลัก | |
| FAQ 4 — Q | ต้องปรับแคมเปญบ่อยแค่ไหน? | |
| FAQ 4 — A | เราปรับเป็นรอบตามข้อมูลที่ได้ ไม่เปลี่ยนเพื่อให้ดูยุ่ง แต่ปรับเมื่อเห็นสัญญาณว่าควรเปลี่ยน audience, creative หรืองบประมาณ | |
| FAQ 5 — Q | ดูแลเฉพาะ Meta และ Google หรือไม่? | |
| FAQ 5 — A | Meta และ Google เป็นช่องทางหลัก แต่สามารถประเมิน TikTok, LINE Ads หรือ YouTube ได้ตามพฤติกรรมลูกค้าและเป้าหมายของธุรกิจ | |
